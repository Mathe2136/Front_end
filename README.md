# Estudos de Front-end

Repositório em preparação para organizar meus estudos de desenvolvimento de interfaces.

## Estado atual
O repositório contém uma estrutura inicial de pastas e arquivos `temp` usados como marcadores. Ainda não há uma aplicação executável.

## Organização atual
A pasta `src ` reúne diretórios destinados a componentes, estilos, recursos, documentação e arquivos públicos. Alguns nomes possuem espaços extras e precisam ser padronizados antes de adicionar a aplicação.

## Próximas etapas
- Padronizar os nomes das pastas.
- Adicionar a primeira página com HTML, CSS e JavaScript.
- Documentar as funcionalidades e instruções de execução.
- Incluir uma captura de tela e uma demonstração quando a página estiver pronta.
